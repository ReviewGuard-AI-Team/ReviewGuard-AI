# 🚀 ReviewGuard AI – Fake Review Detection Using Machine Learning

## 📌 About the Project

ReviewGuard AI is a machine learning-based web application that analyses online product reviews and predicts whether the text is computer-generated or original human-written.

## 🎯 Project Domain
- Domain: Retail / E-commerce
- Subdomain: Natural Language Processing (NLP)
- Learning Type: Supervised Learning

## 🛠️ Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- Matplotlib
- TF-IDF Vectorization

## 🤖 Machine Learning Algorithms
1. Logistic Regression
2. Naive Bayes

## ✨ Key Features
- Product review analysis
- Multiple machine learning model selection
- Prediction and confidence score
- Model accuracy comparison
- Interactive web interface
